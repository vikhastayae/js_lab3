# Лабораторная работа № 3 — Доска публикаций

Небольшое веб-приложение на HTML, CSS и обычном JavaScript для работы с REST API JSONPlaceholder.

## Запуск

Откройте файл `index.html` в современном браузере. Для запросов к JSONPlaceholder необходимо подключение к интернету.

## Проверка

- Кнопка «Загрузить публикации» отправляет GET-запрос на `https://jsonplaceholder.typicode.com/posts?_limit=5` и отображает пять публикаций.
- Пустой заголовок, пустой текст или значения из одних пробелов приводят к сообщению об ошибке; POST-запрос не отправляется.
- Заполненная форма отправляется POST-запросом с JSON-данными `{ title, body, userId: 1 }`. Ответ сервера отображается на странице вместе с ID.
- Во время запроса показывается сообщение о загрузке или отправке. При сетевой ошибке или неуспешном HTTP-ответе выводится понятное сообщение, а кнопку можно нажать снова.
- Для проверки обработки HTTP-ошибки временно замените адрес GET на `https://jsonplaceholder.typicode.com/postz`, нажмите кнопку загрузки, затем восстановите исходный адрес.

JSONPlaceholder имитирует создание записей: публикация показывается в интерфейсе по ответу API, но постоянно на сервере не сохраняется.

## Файлы

- `index.html` — структура страницы и форма.
- `style.css` — оформление интерфейса.
- `app.js` — обработчики событий и запросы к API.
